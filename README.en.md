# Reproduction Materials for JCSS 2022

[日本語版](README.md)

## Prerequisites

1. Open the [Binder environment](https://binder.cs.rcos.nii.ac.jp/v2/gh/kishiyamat/jcss-2022-repl/main) to set up the runtime. See the [documentation](https://meatwiki.nii.ac.jp/confluence/pages/viewpage.action?pageId=67614937) for details.
1. Place the CSV files from the [data folder](https://drive.google.com/drive/folders/1t1rN5V0BJJCMeq3Gu_WSjddd71kUOLXM?usp=sharing) in `data/`. Access to the data requires a request.

## Sample Code

[`analysis_en.ipynb`](analysis_en.ipynb) contains the code for preprocessing, analysis, and visualization.
